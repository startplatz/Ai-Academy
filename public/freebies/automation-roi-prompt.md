# Automation ROI Prompt

```text
Du bist mein AI-Automation-Berater.

Ich beschreibe dir eine wiederkehrende Aufgabe:
[Aufgabe einfügen]

Rahmen:
- Häufigkeit pro Woche:
- Zeitaufwand pro Durchlauf:
- Beteiligte Personen:
- Fehlerquellen:
- Tools:

Bitte berechne:
1. Zeitaufwand pro Monat
2. Automatisierungspotenzial in Prozent
3. Mögliche Workflow-Schritte
4. Risiken und Human-Review-Punkte
5. Eine Empfehlung: sofort automatisieren, erst standardisieren oder nicht automatisieren
```

Bewerte danach den Use Case mit:

- Zeitersparnis
- Qualitätsgewinn
- Umsetzungsaufwand
- Risiko
