# Bewerbungsstory Prompt Pack

## Prompt 1: Positionierung

```text
Analysiere meinen beruflichen Hintergrund und formuliere eine klare KI-bezogene Positionierung.

Profil:
[Lebenslauf oder Stichpunkte einfügen]

Zielrolle:
[Rolle einfügen]

Erstelle:
- Eine Headline für LinkedIn
- Einen 5-Satz-Bewerbungspitch
- Drei konkrete KI-Kompetenzen, die ich glaubwürdig zeigen kann
```

## Prompt 2: Stellenanzeigen-Matching

```text
Vergleiche mein Profil mit dieser Stellenanzeige.

Mein Profil:
[einfügen]

Stellenanzeige:
[einfügen]

Gib mir:
1. Matching-Score mit Begründung
2. Fehlende Skills
3. Drei Beispiele, wie ich KI-Kompetenz passend belege
4. Eine Bewerbungserzählung in 120 Wörtern
```

## Prompt 3: Interviewtraining

```text
Simuliere ein Bewerbungsgespräch für diese Rolle.
Stelle mir 8 Fragen, darunter 3 zu KI, Automatisierung und Verantwortung.
Nach jeder Antwort gib mir klares Feedback und eine bessere Version.
```
